About the Project

Bytefish is a UCI-compliant chess engine. It started as a hobby project, but quickly became an actual working advanced chess engine, even though it is much worse than engines like Stockfish.

Key Features

  • UCI Protocol Support: Compatible with popular GUIs like Arena, Cutechess, and Bankafi.
  • Bitboard Architecture: Uses bitboards for move generation.
  • Search: Uses Minimax, Alpha-Beta-Pruning and other algorithms for the best move selection.

Technology

Bytefish uses the new programming language Mojo, which combines the structure of Python with the speed of C++.

Compilation & Run

You can build Bytefish using any standard compiler. Here is the quick setup guide:

# Clone the repository
git clone https://github.com/nichtnichtjemand/bytefish.git
cd bytefish

# Build the engine
mojo build main.mojo -o bytefish

# Run the UCI interface
./bytefish
