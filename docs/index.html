About the Project

Bytefish is a UCI-compatible chess engine developed as an independent programming project. It combines search algorithms, position evaluation and move ordering to find strong moves.

Key Features

  • UCI Protocol: Compatible with chess GUIs that support UCI engines.
  • Bitboards: Efficient board representation and move generation.
  • Search: Minimax, alpha-beta pruning and move ordering.
  • Mojo: A performance-oriented implementation.

    Technology

    Bytefish is implemented in Mojo, a programming language designed with performance and Python-like syntax in mind.

    Build & Run

    Clone the repository and compile the engine using a compatible Mojo toolchain. 

    git clone https://github.com/nichtnichtjemand/bytefish.git
cd bytefish

mojo build main.mojo -o bytefish
./bytefish
